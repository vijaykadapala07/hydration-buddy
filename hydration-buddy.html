States and timing

Each travel lasts a whole number of steps, so the legs land in the same pose the next state starts from.

Triggering each animation

Set data-state on the walker, or use the small class below, which also resolves a promise when the walk finishes.

const buddy = new HydrationBuddy(document.getElementById('buddy'));

await buddy.enter();   // walks in, then stays in "idle" with the bubble
await buddy.yes();     // happy walk off to the right, then "hidden"
await buddy.no();      // sad walk back to the left, then "hidden"

// Every change fires an event you can hook into:
el.addEventListener('buddy:state', e => console.log(e.detail.state));
